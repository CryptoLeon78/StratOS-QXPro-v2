- **[G0-07]** Sharpe mínimo de avance UMS (PARTE 7.9) sin valor numérico: seed con `ums_min_sharpe=1.0` (mismo umbral que el gate 3 del pipeline F4+, PARTE 6.3); a confirmar por el operador.

Se fija `mcp<2` como dependencia del tooling (README, `.mcp.json`/venv) en vez de reescribir el server entregado a la API nueva — cambio de código fuera del scope de G0.

Se forzó `npm audit fix --force` → `vite@8.2.2`, 0 vulnerabilidades; build (`tsc && vite build`) verificado verde tras el salto de major. `@vitejs/plugin-react@4.7.0` no declara peer oficial para vite 8 todavía (warning `ERESOLVE` no bloqueante); revisar si aparece una versión de `plugin-react` con soporte explícito antes de G6.

Se remapean a 55432/6380/8100/8180/5273 en el host; los puertos internos entre contenedores (dentro de la red de compose) siguen siendo los estándar.
